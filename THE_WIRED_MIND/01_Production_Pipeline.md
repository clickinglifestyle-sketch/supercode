# THE WIRED MIND — Production Pipeline

## Locked Workflow (Step-by-Step)

1. **Topic selection** — run against 1M criteria filter
2. **Topic Intelligence Report** — niche, audience, hook, structure, retention, length, emotion
3. **Script production** — ~870 words ±5%, structure matches topic complexity
4. **Visual Style** — Wired Mind locked profile (no re-decisioning)
5. **Scene prompts** — Nano Banana 2 / Pro-compatible, 12–15 sec each, no third-party IP, signature character described from scratch each scene
6. **Visual mode** — Static images (Ken Burns / parallax in CapCut or DaVinci Resolve in post)
7. **Metadata package** — 3 titles, full description with chapters, 20–30 tags, pinned comment
8. **Thumbnail** — 5 concepts generated, 1 selected, full prompt finalized
9. **Full production export** — single compiled document

## 1M-Template Format — 3 Profiles

Use for high-potential topics that meet the 1M criteria filter.

### The 3 Profiles
| Profile | Type | Function |
|---------|------|----------|
| Profile 1 | The healthy boundary-setter | Grounding / legitimacy |
| Profile 2 | The anxious/vulnerable type | Empathy / relatability |
| Profile 3 | The psychologically evolved | Aspirational reward |

### 1M Topic Criteria Filter
A topic qualifies for the 1M template when it meets ALL of the following:

- [ ] Behavior practiced by a significant minority
- [ ] Majority quietly judges or misunderstands it
- [ ] Can be reframed from "odd/antisocial" → "psychologically evolved"
- [ ] Creates double audience (the person + people who know that person)
- [ ] Connects to a current cultural tension

### 1M Script Architecture

1. **Hook** — Universal mental image
2. **Surface assumption**
3. **Curiosity signal**
4. **Psychological reframe**
5. **Profile 1** — Healthy boundary-setter
6. **Profile 2** — Anxious/vulnerable
7. **Profile 3** — Psychologically evolved
8. **Research block** — Named study + institution
9. **Cultural observation**
10. **Quotable closer** — Standalone shareable object
